### 踩坑
1. **平台不匹配**：本机 Apple Silicon docker build 默认 arm64，服务器 amd64 → 容器 Restarting(1)。必须 `docker build --platform linux/amd64`（2m11s 模拟构建），docker save|load 后正常。
2. **跨服务协议 bug（已修复）**：control 全局 DateTimeConfig 把 Instant 统一序列化为 `yyyy-MM-dd HH:mm:ss`（前端展示格式），导致 MQTT catalog/sync 快照的 issuedAt/expiresAt 下发为空格格式；Go 网关 model.FixedCameraCatalogSnapshot 用 time.Time 只接受 RFC3339 → 解析失败 → 租约目录功能不可用。
   - 修复：control-service FixedCameraCatalogSnapshot 的 Instant 字段加 `@JsonSerialize(using = ToStringSerializer.class)`（RFC3339），并新增回归测试（用生产同款 ObjectMapper 含 DateTimeConfig 定制器验证）。
   - 注意 Jackson2ObjectMapperBuilder 在 Spring Boot 3.5 位于 `org.springframework.http.converter.json`（spring-web），不在 autoconfigure 包。
   - BFF 只发租约、不解析快照响应体，不受影响；网关无需重建。
   - 验证：curl PUT 内部租约接口（X-Internal-Caller: bigscreen-bff）→ 网关日志「固定摄像头目录快照已更新，网关ID=default 摄像头数=1」。
- 服务器时钟仍慢约 6 分钟（tar future timestamp 警告持续出现），NTP 修复仍未落实（提交记录提到 .58 不可达）。
