## 4. 后续开发的即时约束

新增或修改 Java 代码执行 `sh scripts/quality-check.sh java --base <明确基线>`；当前未提交工作可用 HEAD，审查已提交分支时应指定实际比较目标。涉及 HTTP 契约执行 `sh scripts/quality-check.sh openapi`。动态消息/扩展载荷和外部接口继续使用权威专项文档及对应测试，新增固定字段时同步细化 Schema。

每次关闭问题保留变更、兼容性分析、实际测试和未验证项。新增行为约束、权限收紧、响应字段迁移须单独评估调用方，不能借规范整改附带改变既有协议。后续保留 Management 完整契约、外部扩展字段细化及真实存储、设备、浏览器和 MySQL/Redis 验证的未完成项；不得将本地契约通过写成完整生产验收。
