# 大屏数据统计接口文档

## 1. 约定

大屏前端统一访问 Bigscreen BFF：

```text
/api/bigscreen/statistics/**
```

时间格式：

```text
yyyy-MM-dd HH:mm:ss
```

设备类型不在 BFF 中固定枚举，页面使用总览响应中的 `deviceTypeOptions`。

时间范围：

| 值 | 含义 |
|---|---|
| `all` | 全部 |
| `today` | 今日 |
| `week` | 本周/最近 7 天 |
| `month` | 本月 |
| `custom` | 自定义 |

## 2. 数据统计总览

```http
GET /api/bigscreen/statistics/overview
```

当前不再返回 BFF mock 统计数据。BFF 基于管理端的设备、实时状态、任务实例和告警明细计算已支持的统计字段；缺少可靠数据来源的字段继续返回 `null` 或空数组。

已支持的真实统计：任务总数、任务状态分布与完成率、当前设备在线率、区间巡逻里程及其环比、告警总数、告警类型分布、处理方式分布、高发区域和告警趋势。任务和告警查询会遍历全部分页，并按归一化后的时间范围过滤。

暂无真实来源的字段：自动处置成功率、各设备类型的故障/离线历史时长，以及巡逻里程以外的环比数据。

`deviceTypeOptions` 为设备类型筛选项，机器人整机类型动态取管理端
`/api/v1/management/selection-options/dictionaries/device_type` 字典，BFF 追加
`FIXED_CAMERA/固定摄像头`。前端和报告均使用 `value` 作为筛选编码、`label` 作为展示名称。

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `range` | string | 否 | `all`、`today`、`week`、`month`、`custom`，默认 `month` |
| `startTime` | string | 否 | 自定义开始时间，`range=custom` 时传 |
| `endTime` | string | 否 | 自定义结束时间，`range=custom` 时传 |
| `deviceType` | string | 否 | 设备类型，默认 `all` |
| `areaId` | string | 否 | 区域 ID |

`patrolMileage.value` 的单位为 `KM`。BFF 从 Control 批量查询所选设备在当前

### 统计口径

| 字段 | 当前口径 |
|---|---|
| `kpis.taskTotal.value` | 统计时间内启动的任务实例数 |
| `kpis.aiAlarmTotal.value` | 统计时间内管理端告警明细数 |
| `equipmentRuntime.onlineRate` | 当前在线设备数 / 管理端设备数，是实时快照，不是历史时间范围统计 |
| `equipmentRuntime.taskCompletionRate` | 已完成任务实例数 / 统计时间内任务实例数 |
| `equipmentRuntime.items[].runningHours` | 按任务实例关联的设备类型累计 `durationSeconds`；缺失时用 `startedAt/completedAt` 计算 |
| `alarmAreaRanking` | 仅统计告警数据中能解析出位置名称的记录；当前无稳定区域 ID，`areaId` 为 `null` |
| `alarmTrend` | 单日按小时，62 天内按日，更长范围按月分组 |
| `deviceType` | 任务通过 `deviceSummaries[].serialNumber` 关联设备类型，告警通过 `serialNumber` 关联设备类型 |
| `areaId` | 当前仅回显；告警明细未提供稳定区域 ID，暂不执行区域过滤 |

## 3. 一键生成报告

当前版本同步生成并返回一个 PDF 文件流。报告内容使用同一套统计聚合数据，支持按时间范围、设备类型和内容模块组合筛选。

```http
POST /api/bigscreen/statistics/reports/export
Content-Type: application/json
Accept: application/pdf
```

### 请求体

```json
{
  "modules": [
    "equipmentRuntime",
    "aiAlarmAnalysis",
    "alarmAreaRanking",
    "alarmTrend",
    "taskCompletion"
  ],
  "timeRange": {
    "type": "all",
    "startTime": null,
    "endTime": null
  },
  "deviceType": "all",
  "areaIds": [],
  "alarmTypes": [],
  "handleMethods": [],
  "taskStatuses": [],
  "format": "PDF"
}
```

### 模块枚举

| 值 | 含义 |
|---|---|
| `equipmentRuntime` | 装备运行时长 |
| `aiAlarmAnalysis` | AI 告警分析 |
| `alarmAreaRanking` | 告警高发区域 |
| `alarmTrend` | 告警趋势图 |
| `taskCompletion` | 任务完成率 |

### 时间范围枚举

| 值 | 含义 |
|---|---|
| `all` | 全部 |
| `today` | 今日 |
| `week` | 本周 |
| `month` | 本月 |
| `custom` | 自定义时间，需传 `startTime` 和 `endTime` |

### 设备类型

报告请求中的 `deviceType` 使用总览响应 `deviceTypeOptions[].value`，报告展示名称使用对应的 `label`。

### 成功响应

```http
HTTP/1.1 200 OK
Content-Type: application/pdf
Content-Disposition: attachment; filename*=UTF-8''statistics-report-20260615.pdf
```

响应体为 PDF 二进制文件流。

导出成功后，后端会同步生成一条历史报告记录。当前第一版使用本地文件持久化，服务重启后历史记录仍可查询和下载。

默认存储目录：

```text
data/statistics-reports/
├── index.json
├── 1.pdf
├── 2.pdf
└── 3.pdf
```

可通过环境变量调整：

```bash
STATISTICS_REPORT_STORAGE_DIR=/data/bigscreen/statistics-reports
```

## 4. 历史报告

### 4.1 历史报告列表

```http
GET /api/bigscreen/statistics/reports?page=1&size=10
```

响应：

```json
{
  "data": [
    {
      "id": "1",
      "reportName": "具身智能平台统计报告-全部-全部",
      "downloadTime": "2026-06-29 11:59:30",
      "format": "PDF",
      "status": "COMPLETED",
      "filename": "具身智能平台统计报告-全部-全部-20260629115930.pdf",
      "filePath": "1.pdf"
    }
  ],
  "total": 1,
  "page": 1,
  "size": 10
}
```

### 4.2 下载历史报告

历史报告下载的是指定 `id` 对应的本地原始报告文件，不会重新生成报告，也不会新增历史记录。

```http
GET /api/bigscreen/statistics/reports/{id}/download
Accept: application/pdf
```

响应体为 PDF 二进制文件流。

### 4.3 删除历史报告

```http
DELETE /api/bigscreen/statistics/reports/{id}
```

删除成功返回：

```http
HTTP/1.1 204 No Content
```

### PDF 内容结构

1. 报告标题：固定为“具身智能平台统计报告”，副标题为“巡逻巡查数据统计分析”。
2. 报告概况：生成时间、统计周期、起止时间、设备类型和统计内容。
3. 核心指标：任务执行总数、总巡逻里程、AI 自动识别异常数、自动处置成功率。
4. 业务分析：仅输出请求 `modules` 选中的装备运行、AI 告警、高发区域、告警趋势和任务完成章节。
5. 报告说明：随实际输出的业务章节动态编号，说明数据口径、报告用途和复核边界。

正式版模板使用分层字号、表格表头、页眉和页码。缺失值和空集合统一显示“暂无数据”，不输出 `null`、“`null%`”或开发阶段占位说明。

## 5. 后续真实数据来源建议

| 页面板块 | 建议权威来源 |
|---|---|
| KPI 总数、任务完成率 | 任务服务、告警服务聚合 |
| 装备运行时长 | 设备在线状态、故障状态、离线状态统计 |
| AI 告警分析 | 告警服务 |
| 告警高发区域 | 告警服务 + 区域/地图点位档案 |
| 告警趋势图 | 告警服务按日聚合 |
| 报告导出 | BFF 聚合统计数据后生成文件流 |
