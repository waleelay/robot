| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| TASK-001 | 机器人不支持某项快捷任务 | 页面不显示对应按钮 |
| TASK-002 | 任务已配置但暂不可执行 | 按钮禁用并显示明确原因 |
| TASK-003 | 提交可执行的快捷任务 | 生成唯一 `taskExecutionId` |
| TASK-004 | 观察任务执行过程 | 页面区分已创建、执行中、成功和失败 |
| TASK-005 | 机器人当前地图发生变化 | 不执行旧地图对应的返航任务 |
| TASK-006 | 没有驻点、定位或充电桩 | 不错误创建或执行任务 |
| TASK-007 | 人工控制占用机器人 | 拒绝冲突任务并提示先释放控制权 |
| TASK-008 | 检查消息链路 | 快捷任务不进入本体直接控制 Topic |
| TASK-009 | 任务执行失败 | 页面展示可定位的失败原因 |
| TASK-010 | 查询历史执行记录 | 操作可以按 `taskExecutionId` 查询和审计 |
