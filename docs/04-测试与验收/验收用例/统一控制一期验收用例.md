# 统一控制一期验收用例

| 文档属性 | 内容 |
| --- | --- |
| 文档状态 | 现有验收口径整理 |
| 关联设计 | `../../02-设计/统一控制/具身智能装备统一控制一期设计说明书.md` |
| 关联接口 | `../../03-接口与协议/统一控制/前端-Control-Media服务接口文档.md` |

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| CONTROL1-001 | 查询不同机器人控制画像 | 前端按 `control-profile` 动态展示对应上装控制面板 |
| CONTROL1-002 | 两个终端申请同一本体控制权 | 不能同时获得控制权 |
| CONTROL1-003 | 一个终端控制本体，另一终端申请云台 | 按配置允许设备级并行控制 |
| CONTROL1-004 | 本体或云台点触、长按 | 前端按 10Hz 发送控制帧，后端逐帧校验和组装 MQTT |
| CONTROL1-005 | 无 confirmToken 或安全条件不满足时执行高风险动作 | 服务端拒绝操作 |
| CONTROL1-006 | `NAVIGATION` 下申请手动控制 | 必须完成 takeover 并等待机器人确认 `MANUAL` |
| CONTROL1-007 | 请求携带旧 `observedStateSeq` | 返回 `ROBOT_STATE_CHANGED` |
| CONTROL1-008 | 机器人持续上报状态 | 服务端刷新在线、模式、任务、摄像头和设备状态 |
| CONTROL1-009 | 操作多合一喊话设备 | 按 `actions` 展示并使用统一 payload，下层协议不暴露给前端 |
| CONTROL1-010 | 设备缺少真实状态接口 | 页面只显示“指令已下发”或“状态未同步” |
