# 平台能力验收用例

| 文档属性 | 内容 |
| --- | --- |
| 文档状态 | 需求基线验收场景整理 |
| 关联需求 | `../../01-需求/平台/具身智能装备媒体与大屏平台需求规格说明书.md` |

> 本文只整理平台级验收入口。各能力的详细步骤以专项验收用例为准。

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| PLATFORM-001 | 创建机器人实时视频会话 | 会话创建成功并向设备端客户端发送启动指令 |
| PLATFORM-002 | 获取播放凭证并进入媒体房间 | 浏览器成功连接并订阅机器人媒体轨道 |
| PLATFORM-003 | 切换摄像头或清晰度 | 会话目标更新并完成对应指令发布 |
| PLATFORM-004 | 开启并关闭语音对讲 | 对讲状态正确变化，关闭后视频会话保持 |
| PLATFORM-005 | 机器人发起来电并由中心端接听 | 呼叫进入已接听状态并建立关联对讲 |
| PLATFORM-006 | 来电拒绝或超时 | 呼叫进入对应终态并推送状态 |
| PLATFORM-007 | 分片上传中断后继续 | 已上传分片可恢复，完成后生成完整文件 |
| PLATFORM-008 | 查询已处理视频播放信息 | 返回原文件或 HLS 播放资源及处理状态 |
| PLATFORM-009 | 申请存在冲突的控制会话 | 返回当前控制占用信息 |
| PLATFORM-010 | 接管机器人控制状态 | 控制模式及任务状态更新并推送机器人状态 |
| PLATFORM-011 | 下发已有设备动作 | MQTT 收到设备动作载荷，接口返回指令标识 |
| PLATFORM-012 | 下发设备不支持的动作 | 服务端拒绝并返回明确错误 |
| PLATFORM-013 | 查询大屏总览和设备详情 | 返回统一结构，缺失来源字段保持空值 |
| PLATFORM-014 | 导出统计报告 | 请求内同步生成并下载 PDF；BFF 容器重启后仍可从当前用户报告历史中查询、下载和删除 |
| PLATFORM-015 | 启动固定摄像头视频 | 档案校验、码流选择、Gateway 推流和 LiveKit 观看闭环完成 |
| PLATFORM-016 | 批量启动固定摄像头 | 成功与失败按 cameraId 分离，部分失败不回滚成功会话 |
| PLATFORM-017 | 多合一设备执行已登记动作 | Control 校验参数并发布 multi-function MQTT，客户端执行且状态可观测 |
| PLATFORM-018 | 查询整改前历史分钟桶 | 总里程和样本数不变，返回 `quality=UNKNOWN` |
| PLATFORM-019 | 同一分钟内向既有分钟桶追加新里程 | 总量与样本数正确累加 |
| PLATFORM-020 | 重启 Control 后继续接收里程 | 使用持久化检查点正确计算下一次增量，不重复累计 |
