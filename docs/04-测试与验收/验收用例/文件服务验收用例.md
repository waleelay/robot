# 文件服务验收用例

| 文档属性 | 内容 |
| --- | --- |
| 文档状态 | 待评审 |
| 关联测试方案 | `../测试方案/文件服务测试方案.md` |

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| FILE-001 | 上传允许范围内的小文件 | 创建文件记录并直接进入可用状态 |
| FILE-002 | 创建大文件 multipart 上传 | 返回稳定的 `fileId`、`uploadId`、分片大小和上传 URL |
| FILE-003 | 使用相同 `sourceFileId` 重复初始化 | 恢复同一有效上传会话，不重复创建文件 |
| FILE-004 | 中断后继续上传 | 查询到已上传分片，只补传缺失分片 |
| FILE-005 | 分片不完整时调用 complete | 返回明确错误且上传会话保持可恢复 |
| FILE-006 | 本地源文件大小或修改时间发生变化 | 拒绝错误恢复或创建新的源文件标识 |
| FILE-007 | 视频完成上传 | 原文件合并后进入 `PROCESSING`，HLS 完成后进入 `READY` |
| FILE-008 | 查询、播放和下载已完成文件 | 返回有效授权和完整资源 |
| FILE-009 | 并发超过服务限制 | 返回明确限流错误，不产生重复 ACTIVE 会话 |
| FILE-010 | 删除文件 | 数据状态更新，对象存储中的源文件和派生资源被清理 |
| FILE-011 | 上传会话过期 | multipart 被中止，临时资源被清理 |
| FILE-012 | 客户端在 `READY` 后执行本地保留策略 | 服务端文件仍可访问，本地 manifest 状态正确 |
