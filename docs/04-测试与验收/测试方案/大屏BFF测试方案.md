## 1. 测试范围

- 全景总览、设备详情、任务、告警和统计接口。
- 字段来源、空值、缺失数据和枚举转换。
- 下游超时、错误响应和不可用场景。
- 任务计划、流程定义和执行记录的业务白名单代理；当前不测试未实现的快捷任务专用接口。
- WebSocket 桥接、事件转换、重连和重复事件。
- Nginx 反向代理、跨域和 hop-by-hop Header 过滤。

## 2. 测试策略

1. 对每个聚合字段核对字段来源映射文档。
2. 下游无数据时验证返回 `null`、空集合或明确状态，不生成生产假数据。
3. 分别模拟管理、控制和媒体服务超时及错误。
4. 验证 REST 快照与 WebSocket 增量最终一致。
5. 通过直连 BFF 和 Nginx 两种入口执行接口测试。
6. 对全景任务来源分别模拟详情 404、列表连接超时、读取超时、并发许可耗尽和执行器队列饱和；
   核对 `dataQuality.tasks`、部分数据保留与页面不弹出任务数据降级提示。
7. OIDC 登录成功后核对地址栏、浏览器历史、Referer 和 Nginx 日志不含授权码；交换失败时
   回调参数仍保留，业务查询参数和 hash 路由不丢失。
8. 分别在大小写不敏感与大小写敏感文件系统执行 `robot-ui` 生产构建，确认不存在
   CaseSensitivePaths 告警；对巡检监控页、控制中心内嵌面板和 GIS 弹窗执行云台按下/松开、
   自动旋转、模式切换、控制权获取及键盘控制冒烟测试。
9. ESLint 门禁整改后确认 `npm run lint` 实际扫描 `.js/.vue` 业务源码，而不是“成功执行但零文件”
   或“所有文件均被忽略”；使用临时错误用例验证 CI 能稳定阻止新增违规代码。
10. 构造嵌套任务、慢下游和重复满页分页，验证 Overview 在 8 秒内返回成功或明确失败；连续刷新
    不得出现浏览器 300 秒主动断开的 `499`。前端应在 15 秒后退出加载态并显示可恢复错误提示。
11. 保持媒体客户端状态上报，仅停止机器人边缘状态：页面须在 30～31 秒内通过 WebSocket 动态变为
    `offline`，刷新 Overview 后状态一致；恢复第一条合法、非 retained 边缘状态后立即恢复
    `online/fault`。并发刷新、多标签页、WebSocket 重连和同一秒内离线/上线时，旧事件不得覆盖
    `statusChangedAt` 更新的状态。
12. 准备 60 条以上带不同截图的未处理告警，首次进入全景地图时只允许可视区及前后 100 px 内的
    缩略图请求，折叠分组不得预取；滚动、展开后按可视范围继续加载，打开详情时加载当前告警多路图片。
    同一 `fileId` 只请求一次，不同文件内容请求同时在途数不得超过 4。

## 3. 构建与接口检查

### 地图刷新一致性回归（PROD-026）

- 选中非首张 SLAM 地图后刷新 Overview，检查底图 ID、工具栏当前地图及侧栏任务地图一致；
  只请求该图的 `resources/task-routes`，列表重新排序或 GPS 设备变化不得覆盖选择。
- 分别在等待 Overview、等待地图资源时切图，延迟旧请求返回，确认最终展示用户最新选择，
  旧快照或非当前图的响应不写入点位/任务；同图在途请求合并。
- 成功返回列表但所选地图移除时统一回退；全部地图移除时统一 GIS。手动 GIS 的普通刷新保持 GIS。
- 地图 HTTP 401/403 保持原状态；502、读取超时、空响应及通用并发饱和应明确失败，
  不返回成功空列表。普通失败保留已有地图；明确失权刷新先清空，旧普通刷新不能恢复失权地图。
- 退出期间延迟返回 Overview 或地图响应，确认不恢复旧地图；新登录重新默认选图。
- 线上在首页和实时监控分别选择非首张图，跨至少两次真实 Token 续期，并在续期期间切图，
  核对底图、任务、点位、路径和装备选择一致，无整页重载；本地测试不能代替此验收。

通过 Nginx 联调时使用实际测试环境地址，不在文档中固化本机 IP。

## 4. 退出条件

- 接口字段与数据来源映射一致。
- 下游异常不会转换为看似真实的成功数据。
- WebSocket 重连后能够恢复快照与增量。
- Overview 与 WebSocket 的机器人 `status/statusChangedAt` 使用同一 Control 注册表，媒体状态不能延长在线时间。
- 业务白名单代理的允许路径和拒绝路径均有执行结论。
- 任务降级不会在全景页、统计页或 PDF 中表现为真实的零值；401/403 不被降级吞掉。
- 所有参与 JWT、授权快照和目录租约的节点执行 `MAX_OFFSET_SECONDS=1 sh scripts/check-time-sync.sh` 通过。
