# 实时监控列表选中状态整改验收记录（2026-09-24）

## 1. 验收目标

验证实时监控一级页面和“轮式机器人R1”控制中心中，左侧列表选中状态始终与当前视频墙槽位一致，并确认页面切换只释放当前视频墙拥有的视频消费者。

## 2. 变更范围

- 一级装备列表高亮由一级视频墙槽位状态驱动，不再读取全局 `activeCameras`。
- 二级摄像头列表高亮由二级视频墙槽位状态驱动，不再读取全局 `activeCameras`。
- 普通机器人摄像头与固定摄像头统一使用页面实例级视频墙 `consumerId`，隔离同一业务墙快速销毁、重建时的迟到释放。
- 进入控制中心、二级返回和组件销毁时，仅释放对应视频墙槽位，不再遍历并关闭全局活动视频。
- 地图跟随、任务列表联动改为读取对应视频墙的选择结果。

本次只更新 `robot-ui` 静态资源，不修改后端、Control、BFF、数据库或协议。
