## 1. 变更

- 共享发布模式从 `FIXED_CAMERA_GATEWAY` 迁移为 `EDGE_MEDIA_GATEWAY`，RTMP 的 `LIVEKIT_INGRESS` 保持不变。
- Control 下发及订阅改用 `gateway/media/**`，固定摄像头 start/restart 增加 `sourceProtocol=RTSP`，不再携带地址。
- BFF 授权 HTTP 仍使用固定摄像头业务模型；Control 将有效租约转换为通用 MQTT `sources[]`。
- Gateway 消费平台目录，拒绝跨实例、陈旧版本、retained 和超长租约；租约过期或撤销时精确释放对应源绑定。
- 固定摄像头不能回退本地配置绕过授权；目录与 start 跨 Topic 时允许有界等待，不无限排队。
- 租约失效停止由 Media 同步关闭 viewer、录像和旧会话，迟到状态不复活；续租后使用新 session 重新观看。
- 多用户租约按授权并集合并有效期限，短租约不会缩短其他身份的长期有效授权；不完整源被过滤。
- 视频和健康状态在 Control 按源类型、摄像头与 Gateway 身份检查；保留消息不刷新状态。
- 删除旧 Gateway 命令入口及重复固定目录实现，镜像入口统一为 `media-gateway`。
- Compose 使用新 Gateway 身份与运行参数，发布物名称暂沿用原离线包约定；打包通过协议标签拒绝旧镜像。
- 前端补充统一源错误原因的安全中文展示，播放接口、Room 命名和固定摄像头授权范围保持原有语义。

## 3. 发布前操作与待验收

1. 停止旧 Gateway、Control 和 Media，并备份 Media 数据库。
2. 执行[发布模式迁移脚本](../../../deploy/database/20261010-migrate-edge-media-gateway.sql)，确认旧模式记录为 0。
3. 管理端调用 `/internal/control/**` 发布模式编排时，将旧 `targetMode` 更新为 `EDGE_MEDIA_GATEWAY`。
   管理端不在本仓库，本批未修改或验证其代码、配置与部署。
4. 更新现场 `.env` 的 Gateway 相关参数为 `MEDIA_GATEWAY_*`，配置 `gateway/media/{gatewayId}/**` MQTT ACL。
   BFF 目录租约、固定摄像头健康超时和管理端可信调用方等业务参数继续使用原配置名。
5. 构建带 `robot.media-gateway.protocol=edge-media-v1` 标签的新镜像，再部署同一版本的 Control、Media 与 Gateway。
   旧离线镜像无法通过新打包门禁。
6. 用真实 RTSP、MQTT、LiveKit 与浏览器验收首帧、H.265 转码、多人观看、录像、断网恢复、撤权及停止后清理。
