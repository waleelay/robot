# 大屏统一入口迁移预检执行记录

> 版本：V1.0
> 执行日期：2026-10-20
> 状态：切换前预检已完成

## 1. 范围与环境

本次核对生产 IAM/Keycloak、IAM API Gateway、大屏 BFF、Nginx 访问记录及本仓库部署配置，并在本地准备 4443 大屏 REST 网关路由候选配置。使用已授权的测试账号按 `bigscreen-web`、`field-app` 各自的授权码加 PKCE 流程取得短期令牌；用户 JWT 只保留在进程内存中，未写入仓库、执行记录或请求 URL。HLS 清单按现有协议使用短期播放签名访问。未发布配置、重载 Nginx、重建容器、修改业务数据或使用真实设备。

访问记录覆盖 2026-09-24 至 2026-10-20。统计只输出路径类别、HTTP 状态、客户端类型、来源页面类别和数量，不保存原始 IP、文件 ID、签名 URL 或令牌。

## 3. 直连入口使用情况

在 2026-10-19 至 2026-10-20 的 `/api/bigscreen/**` 直连请求中：

| 客户端类别 | 请求数 | 来源特征 | 观察到的主要路径 |
| --- | ---: | --- | --- |
| Dart HTTP 客户端 | 834 | 一个请求来源；本机可见的 `eiop-app` Flutter 工程配置了 `/api/bigscreen/**` 直连路径，实际运行构建尚未核对。 | 全景查询、控制操作，既有成功也有 4xx。 |
| Edge 浏览器 | 1,280 | 一个请求来源，Referer 为 `localhost:8080/bi`；对应本仓库 `robot-ui` 的默认开发端口与代理规则。 | 全景、业务、控制及访问上下文。 |
| Python HTTP 客户端 | 50 | 一个请求来源，无页面 Referer；不能据此判定正式消费者。 | 只读查询与少量接口探测。 |

`robot-ui/vue.config.js` 的开发服务默认监听 8080；`/dev-api` 代理会把普通 `/api/bigscreen/**` 请求改写到远端 `/api/**` 直连入口，仅 HLS 改写到 `/api-gw`。日志 Referer 与此一致，可以将这批 Edge 请求归入本地联调流量。Dart 请求与这批 Edge 请求使用同一个出口地址；共享出口不能证明来自同一设备。本机当前可见的 Flutter 工程为 `/Users/leelay/Documents/eiop-app`：`lib/config/server_endpoints.dart` 将全景、任务和控制 REST 配为 `/api/bigscreen/**` 直连；告警客户端实现了 `download-url` 调用，任务客户端也使用该业务入口。该工程仍有部分 Mock 业务，且尚未核实日志中的 Dart 请求对应的实际安装包是否由这份源码构建；仅凭 User-Agent 和源码不能确认运行构建或把这批流量列为正式 App 契约。上述日志窗口未观察到大屏命名空间下的文件正文或 HLS 请求；另有 `/api/control/**` 直连正文和 HLS 请求各一条。这些观察不能作为永久删除相关路径的依据。

`robot-ui/vue.config.js` 的注释称 `play-url` 改走 `/api-gw` 会返回 403；本次用真实 `READY` 视频和当前测试账号直接调用网关得到 HTTP 200，说明该注释不能作为现网路由必须绕过网关的依据。开发代理及注释的调整由前端维护方在入口联调时同步完成。

2026-10-20 的 Dart 直连控制请求集中在 `POST /api/bigscreen/control/files/{fileId}/download-url`，同一路径既有 HTTP 200 也有大量 HTTP 404。404 在入口迁移前已存在，需由 App 与文件服务核对文件 ID、归属和生命周期，不能归因于拟议的网关路由。

## 4. 未完成的验收

1. 移动 App 当前仍有部分 Mock 业务，与大屏、管理端使用相同账号，但 `field-app` 与 `bigscreen-web` 令牌仍有不同的 BFF 路由权限。本机可见源码实现了日志涉及的 `/api/bigscreen/**` 和文件 `download-url` 路径；Dart 流量对应的实际安装包版本及文件 ID 来源尚未核对，不能把该流量直接当作正式上线契约。
2. 当前没有独立测试环境；测试 BFF 与测试网关均未就绪，测试入口不能复用当前指向生产 BFF 的网关路由。正式入口切换仍须先具备受控验证及回退条件。
3. 真实文件的预签名下载正文、HLS 分片、浏览器实际播放、WebSocket 重连、文件上传、控制操作及 Management 业务拒绝场景尚未按新入口逐项验收；本次验证了真实图片下载地址、真实视频播放地址的生成及现有签名 HLS 清单读取。
4. `/api/**` 直连调用方迁移、正式 Nginx 路由切换、部署后验证和回退演练均未执行。部署脚本默认跳过已有 Nginx 配置，正式发布需对现网配置做单处备份、替换、语法检查及可恢复的重载，不能假定仓库模板变更会自动生效。
