## 1. 变更范围

生产 4443 的普通 `/api-gw/api/bigscreen/**` HTTP 请求经 Nginx 转发至 IAM API Gateway，再由网关路由到 Bigscreen BFF。Nginx 去掉 `/api-gw` 前缀，透传浏览器原始 `Authorization`，公开请求 URL 不变。IAM API Gateway 的 CORS 允许来源增加正式大屏的 HTTPS 4443 来源，保留原有管理端来源。

签名 HLS 专用规则、`/ws/bigscreen`、24443 测试入口和 `/api/**` 直达入口未调整。当前没有独立测试环境；本次使用生产入口实施受控切换、回退和再次切换。

## 3. 首次切换期间的异常与定位

| 核对项 | 实际结果 |
| --- | --- |
| 测试账号请求 | 新签发的 qihang `bigscreen-web` 令牌访问当前用户、全景、统计、任务、视频会话和文件列表，公开入口均返回 HTTP 200；真实图片下载地址和视频播放地址生成也返回 HTTP 200。该脚本请求未携带浏览器的 `Origin`。 |
