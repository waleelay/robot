## 1. 实现范围

原固定摄像头运行逻辑移动到 `internal/gateway`，启动和观测逻辑移动到 `internal/app`。
新增 `cmd/media-gateway`，共用 Publisher、命令调度、去重和终止水位；原入口继续对接现有固定摄像头契约。
新入口支持固定摄像头与无人机本地 JSON 源映射、统一媒体 Topic、RTSP 协议适配和 H.265 转码选择。

竞态测试发现原强制清理线程读取 `Cmd.ProcessState` 与 `Cmd.Wait` 写入冲突，已使用原子运行态替换。
子进程 stdout/stderr 缓冲加入互斥保护，避免并发诊断读取。共享核心日志文案统一使用“媒体网关”，旧入口
的 MQTT 字段、Topic 和指标前缀保持原契约。

## 2. 实际验证

在 `fixed-camera-gateway/` 执行并通过：

```bash
go test ./...
go test -race ./...
go vet ./...
go build -o /tmp/robot-edge-media-gateway ./cmd/media-gateway
go build -o /tmp/robot-fixed-camera-gateway ./cmd/fixed-camera-gateway
```

覆盖原固定摄像头目录租约、源健康、MQTT 断开、会话终止和 Publisher 生命周期回归。
新增验证包括受控源与摄像头隔离、非法/重复/超大配置、协议不匹配、编码识别与探测异常脱敏、
统一 Topic 订阅、非法及 retained 命令拒绝、H.265 直接选择转码命令、多 viewer 复用、混合源独立停止、
迟到 restart 拒绝，以及 HTTP 就绪和指标命名空间。

混合源生命周期测试实际启动和停止本地受控子进程；媒体探测、MQTT 发布与转码选择使用替身。
它们验证进程复用、清理和路由，不证明实际视频已经转码或发布到 LiveKit。

本批未修改 Java 或六份 Java HTTP OpenAPI 契约，因此未运行 Java 规范扫描和 Java 契约回归。
Go 观测接口行为由 `httptest` 验证。构建产物仅位于临时目录。

## 3. 尚未验证与后续门禁

- 未验证真实 LTE-LINK SE、非攻透传 RTSP 和视频编码，当前没有现场设备联调证据。
- 未验证真实 MQTT Broker 与 LiveKit 发布、断流恢复、浏览器首帧和 Egress 录像。
- 未构建 Docker 镜像或修改生产 Compose 启动方式，未替换部署服务。
- 未迁移 Control、Media、管理端档案、数据库枚举、OpenAPI 和前端至统一媒体契约。
- 未实现飞控 UDP/MAVLink 适配以及 RTMP、GB28181、RTP/UDP、MPEG-TS、SRT 输入。

完成契约迁移和真实链路验收后，再切换生产入口并删除旧固定摄像头 Topic 与发布枚举。
目标与剩余工作见[无人机视频与位置接入设计说明书](../../02-设计/实时视频/无人机视频与位置接入设计说明书.md)。
